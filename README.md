# Fingerprint Pulse 0.7 — Native Theme Beta

Samsung Galaxy S23 / One UI 9. Original Samsung enrollment drawing, movement, native scan timing, progress, success checkmark reveal and Done button behavior are preserved. The ring uses colors sampled from the reference recording (right-hand phone at 3.7 seconds). Idle ring is nearly invisible; native fingerprint bitmap is tinted gray at rest and cyan-purple during native scan state 2. Native state 4 completion path is themed blue to purple without changing the success event, check timing or completion geometry. Device-selected font is left untouched, including the percentage and Done button.

Enable only Samsung Biometrics (com.samsung.android.biometrics.app.setting) in LSPosed, reboot, enable Dark mode and add a fingerprint through Settings. No overlay, simulated enrollment or external timers. Disable module and reboot to restore stock. Unsupported fields fall back to original drawing. Completion appearance and live visual match remain unverified on device. The original reference source is unavailable. Debug signing keys can vary; if an update reports a signature mismatch, uninstall the previous module, install this build, re-enable scope and reboot.

Download the FingerprintPulse-beta artifact from the successful GitHub Actions run for version 0.7.

0.7: reference frames at 2.5, 3.0 and 4.1 seconds show a fixed dense gray dot field behind the idle fingerprint. The field is rendered at full texture opacity in idle, including before first touch. Native per-scan progress drives its redistribution into an annulus, then dissolves the annulus as the colored ring fills. Progress is read inside the bitmap draw hook after Samsung updates it, not in the preceding onDraw hook. No new timer, authentication modification or simulated progress. Texture appearance and runtime hook compatibility still need device testing.

0.7 adds a one-shot 190 ms guide entrance matching the new reference's sequence: icon first, cool-gray dot field second. It starts at the first actual native guide draw, lets native panel timing stand, ends immediately on active scanning or disabled system animations, and requests frames only during that short entrance. Denser brighter stipple and a subtle blue radial background persist during idle. Dot spread and dissolve during scanning remain synchronized to native progress. Visual fidelity and runtime frame rate require device verification.
