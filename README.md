# Samsung Face ID — 0.1 experimental visual theme

Separate LSPosed module, independent of Fingerprint Pulse. Inspired by supplied 133013.mp4. Uses native Samsung face renderer and native scan paths/progress; white radial ticks, green registration progress, early positioning brackets, cyan scan strokes, dark registration UI, introductory smile illustration and native completion transition. Settings preference rename through the verified FaceSettingsPreferenceController. Actual camera preview and Samsung error, accessibility, enrollment and authentication behavior remain intact. No added second scan, mask enrollment or depth sensing; Galaxy S23 does not have Apple TrueDepth. Original reference animation source is unavailable and exact appearance is not verified. Test on supplied S23 firmware. Scope Samsung Biometrics and Settings only; reboot. Disable and reboot to revert. Do not delete your existing biometric credentials just to test this beta. Build artifacts are debug-signed. Main branch remains the fingerprint module.
