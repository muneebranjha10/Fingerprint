# Samsung Face ID 0.2 reference beta

Separate visual-only LSPosed module for the supplied Samsung S23 firmware. Source reference: 133013.mp4 (21.3 seconds). Compared white, green and blue regions of the recording at 0.3, 4, 6, 7, 10, 12, 17.5 and 18.5 seconds. The filmed display and compression prevent recovery of the exact source colors. Palette approximations: white #FEF9FB, green #A6EFB3, cyan #36B9E8. Short white ticks lengthen to mint ticks on real native progress; thin white positioning circle; cyan tapered ribbon follows native scan paths with dark blue trace; native completion draws a thin mint outline instead of the stock check. Native camera preview, guidance, enrollment result, errors and security remain untouched. No synthetic second scan or mask enrollment. No TrueDepth capability. Intro graphic and visual timings are approximations, not copied assets. Scope Samsung Biometrics and Settings, reboot. Never remove existing biometric credentials just to test. Disable the module and reboot to revert. Main branch remains fingerprint. Debug signing and reflective hook compatibility need on-device testing.
