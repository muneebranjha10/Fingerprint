# Fingerprint Pulse 0.9 — Registration help and both color modes

For the supplied Galaxy S23 firmware. Shows Samsung's original fingerprint registration help page for fresh normal enrollments, even when the caller requests skipping it. Samsung's own Register button, original 60 fps tutorial clip, playback and enrollment logic remain intact; the tutorial's green colors receive a blue chroma tint via TextureView layer paint. This is not the original reference tutorial asset or an exact gradient reproduction. No changes to setup wizard, talkback, or recreated guide sessions. Enrollment visuals enabled in both system light and dark mode, with a black reference panel and white text; native device font remains untouched. Stipple diameter increased from 3.7 to 4.9 texture pixels (32% larger) in idle, and active dots enlarged. Native scan rate, progress, completion and touch logic remain unmodified. Actual display compatibility and tutorial recoloring require device testing.

Install the successful 0.9 artifact, scope only Samsung Biometrics in LSPosed and reboot. Disable module and reboot to revert. If an update reports a signing conflict, uninstall only the module and reinstall it.
