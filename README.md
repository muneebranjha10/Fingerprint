# Fingerprint Pulse — direct reference edition

The uploaded 133067.mp4 is a direct recording of fingerprint enrollment, not face enrollment. This branch uses actual cropped artwork from that recording: 320 x 320 idle, full ring, bright icon, and dotted annulus sprites plus a cropped tutorial movie. The real Samsung guide supplies the position, per-scan progress, error state, and success event. No fake enrollments or security hooks. Upon successful sprite rendering only, the old decorative ring is suppressed; native rendering remains available as fallback. The native success check remains recolored as before. Device font retained. The tutorial movie is replaced only at its original verified Samsung static portrait-help resource, with the original native player and Register button. The movie is from the compressed approximately 21 FPS recording, not original source art; native UI timing and positioning can differ on different firmware.

## Build

Add the supplied reference_assets.zip (do not extract it) into app/src/main/assets/ on the fingerprint-reference branch. That upload triggers the GitHub Actions build. The workflow verifies the ZIP. Do not install an earlier build from this branch without the asset pack. Scope Samsung Biometrics only in LSPosed and reboot. The original main and samsung-face-id branches are not modified. Actual hook compatibility and appearance still require on-device validation. Do not delete stored fingerprints merely for testing; disable module and reboot to revert.
