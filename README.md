# Fingerprint Pulse Beta

Experimental LSPosed module for Samsung fingerprint enrollment. Cosmetic drawing only; no authentication or enrollment logic is replaced. Target: Galaxy S23 / One UI 9. Enable only Samsung Biometrics (`com.samsung.android.biometrics.app.setting`) in LSPosed and reboot. Disable the module and reboot to restore stock rendering. The app includes a simulated animation preview; device compatibility and visual fidelity are not yet tested.

Build from GitHub Actions → Build Fingerprint Pulse APK → Artifacts. This is an experimental debug-signed build.
